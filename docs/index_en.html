Publish Gate Criteria for Safe Data Distribution

High-risk (risk_score >= 70) and sensitive profile data products must pass the following 4 verifications.

1. Asset Readiness Score >= 70

Quality and readiness scores of all connected source assets must meet minimum thresholds.

2. Required Approval Trace Matrix Complete

Approval evidence (Approved/Waived) from all 3 stakeholders — Data Owner, Legal, Compliance — must be valid.

3. Evidence Pack Generation Verified

A complete JSON Pack including product definition, risk review, and contract terms must be generated.

4. Approval Expiry Auto-Detection

Expired approval evidence is not recognized as valid and returns a 409 Conflict error.
