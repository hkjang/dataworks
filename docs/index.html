DIGITAL DATA REFINERY

Data Works는 무엇을 하나요?

흩어진 데이터가 고객이 사용할 수 있는 상품이 되기까지 필요한 판단과 증적을 하나의 흐름으로 만듭니다.

01 · NODE

어떤 데이터가 상품 재료인가요?

자산의 최신성, 완전성, 스키마와 문서화 상태를 평가해 상품화 가능한 원재료를 찾습니다.

데이터 자산 · 준비도
02 · STATION

상품 아이디어는 어떻게 설계하나요?

AI 상품 공장에서 고객 문제, 제공 가치, 가격과 성공 기준을 블루프린트로 구성합니다.

AI Factory · Canvas
03 · GATE

왜 아직 출시할 수 없나요?

준비도, 위험, 승인과 증적을 검사하고 부족한 조건과 다음 행동을 직접 알려줍니다.

Release Gate · Evidence
04 · PACKAGE

출시 후에도 운영할 수 있나요?

계약과 운영 데이터는 백엔드 API로 이어집니다. 상품 작업 공간은 계약을 표시하며 사용량·수익 등 일부 탭은 확장 방향을 안내합니다.

Contract · Runtime · Value

PRODUCTION FLOW

데이터 상품은 어떤 흐름으로 만들어지나요?

각 단계의 상태가 완료·진행·경고·차단으로 연결되므로 생산선이 멈춘 지점을 바로 찾을 수 있습니다.

  1. 01자산원재료 발견
  2. 02아이디어시장 기회
  3. 03블루프린트상품 설계
  4. 04위험정책 검사
  5. G-01승인·증적출시 검문
  6. 06출시상품 배포
  7. 07계약·운영가치 측정

FACTORY FLOOR

AI 실행도 감사할 수 있나요?

예. 모델, 프롬프트 버전, 지연 시간, 토큰, 비용과 평가 결과를 실행 단위로 기록하며 재현 가능한 AI 상품화 공정을 만듭니다.

  • 스트리밍을 기본으로 하는 AI 호출
  • 최대 262,144 토큰 설정 고려
  • 실행 재생과 품질 평가
  • Data Works Copilot 연결

RELEASE GATE

출시가 막힌 이유를 바로 알 수 있나요?

예. 단순 오류 대신 조건별 통과 여부, 전체 준비도와 차단 이유를 시각화하고 필요한 승인 요청으로 연결합니다.

  • 자산 준비도 기준 확인
  • 데이터 오너·법무·준법 승인
  • Evidence Pack 존재와 만료 검사
  • 계약·SLA·마스킹 운영 신호

OFFLINE READY

인터넷이 없는 운영망에도 배포할 수 있나요?

가능합니다. 릴리즈의 단일 Docker 이미지 아카이브를 반입해 네 가지 환경변수만 지정하면 됩니다. 런타임에 프런트엔드 CDN이나 외부 폰트를 요구하지 않습니다.

POSTGRES_DSNBOOTSTRAP_ADMINBOOTSTRAP_ADMIN_PASSWORDENCRYPTION_KEY
offline-install.sh
# 이미지 아카이브 적재
gunzip -c dataworks-v0.9.49.tar.gz | docker load

# 네 가지 필수 환경변수로 실행
docker run -d --name dataworks -p 8080:8080 \
  -e POSTGRES_DSN \
  -e BOOTSTRAP_ADMIN \
  -e BOOTSTRAP_ADMIN_PASSWORD \
  -e ENCRYPTION_KEY \
  dataworks:v0.9.49

Data Works에 대해 자주 묻는 질문

도입 전에 가장 많이 확인하는 운영, 보안과 연동 질문에 직접 답합니다.

Data Works는 무엇을 해결하나요?

분산된 데이터 자산을 상품 후보로 발견하고 준비도, 위험, 승인, 증적, 계약을 확인한 뒤 API나 리포트로 출시하는 전 과정을 하나의 작업 공간으로 연결합니다.

인터넷이 없는 환경에서도 운영할 수 있나요?

가능합니다. 단일 Docker 이미지 아카이브를 운영망으로 옮기고 PostgreSQL 연결, Bootstrap 관리자와 암호화 키를 설정해 실행합니다.

출시 게이트는 무엇을 검사하나요?

자산 준비도, 데이터 오너·법무·준법 승인, Evidence Pack, 승인 만료와 필요한 운영 설정을 검사해 출시 가능 여부와 차단 이유를 보여줍니다.

Keycloak과 개인 API 키를 지원하나요?

Keycloak OIDC와 PKCE 로그인을 지원합니다. 개인 키는 발급 후 권한을 조정하고 정책을 유지한 채 회전하거나 폐기할 수 있습니다.

AI와 외부 도구는 어떻게 연결하나요?

AI 호출은 스트리밍을 기본으로 하며 최대 262,144 토큰 설정을 고려합니다. OpenAPI 3.1, Swagger와 MCP 인터페이스로 외부 도구를 연결합니다.
